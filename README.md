# LinkedIn-PostGen


Generate LinkedIn posts using AI based on topic, length, and language.

🔗 **Live app:** https://linkedin-postgen-ep25t8yeydmuvr5terjoaw.streamlit.app/

## Tech Stack
- Python
- Streamlit
- LangChain
- Groq (LLaMA)

## Setup

```bash
git clone <your-repo-url>
cd LinkedIn-PostGen
pip install -r requirements.txt
```
